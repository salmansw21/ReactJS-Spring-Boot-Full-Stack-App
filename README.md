# ReactJS-Spring-Boot-Full-Stack-App

A full-stack Employee Management System built with **ReactJS, Spring Boot, and MySQL**.

## Technologies

* ReactJS
* JavaScript
* Bootstrap
* Axios
* React Router DOM
* Spring Boot
* REST API
* Spring Data JPA / Hibernate
* MySQL

## Features

* Add Employee
* View Employees
* Update Employee
* Delete Employee
* REST API integration
* MySQL database integration

## Run the Project

### Backend

Configure MySQL in `application.properties` and run the Spring Boot application.

Backend:

```text
http://localhost:8080
```

### Frontend

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

Frontend:

http://localhost:3000
